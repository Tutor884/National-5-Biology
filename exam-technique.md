# 🎯 Exam technique — how marks are actually awarded

## Command words

| Word | What to give | Typical length |
|---|---|---|
| **State / Name / Give** | The fact, nothing more | A few words |
| **Identify** | Pick from the data or diagram given | A word or number |
| **Describe** | **What** happens — the sequence | One point per mark |
| **Explain** | **Why** it happens — the mechanism | One linked reason per mark |
| **Compare** | Both sides, explicitly linked ("A is…, whereas B is…") | Both halves or no mark |
| **Suggest** | A reasonable idea from your biology — several answers may be accepted | One point per mark |
| **Predict** | Continue the trend in the data | A value or direction |
| **Calculate** | The number **with its unit** | Show working |

## The marks-per-point rule

**Marks tell you how many separate points to make.** A 3-mark question needs **three distinct points**, not one point written three ways. If you have written two sentences that say the same thing, you have one mark.

## Data questions — the checklist

- Read the **axis labels and units** before the question
- For "describe the trend": say the **direction**, then quote **figures with units** from the data
- For "at what point…": read from the **graph**, don't estimate from memory
- Check whether the question asks about the **whole graph** or **one section**

## Graph drawing — the four marks

1. **Scale** — use the axes given; use at least **half the grid**
2. **Labels** — both axes, **with units**
3. **Plot** — accurate points, **ruled straight lines** between them (unless told otherwise)
4. **Key** — if there is more than one line

## Experimental design — memorise these

| Asked | Answer |
|---|---|
| Improve **reliability** | **Repeat and calculate an average** |
| Improve **accuracy of an optimum** | Test **more values at narrower intervals** around the peak |
| Purpose of the **control** | To show the results were **due to the factor being tested** |
| Why is the conclusion **not valid** | Only **one** factor measured / other variables not controlled / only one trial |
| Name two variables to **keep constant** | Any relevant one except the independent variable |

## Time management

Roughly **1 minute per mark**, plus reading time. If a question is taking three times its marks in minutes, move on and come back.

## The last five minutes

1. Check every **calculation has a unit**
2. Check every **"explain"** has a *because* / *so that* in it
3. Check nothing is **blank** — a sensible guess costs nothing
